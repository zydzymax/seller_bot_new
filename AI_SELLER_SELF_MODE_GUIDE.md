# 🤖 AI Seller Self Mode - Руководство

## Что это?

**AI Seller Self** - это режим бота, в котором он продает сам себя! То есть продает услуги внедрения AI-ботов для автоматизации продаж в любую нишу.

## 🎯 Возможности

### Два режима работы:

1. **textile_manufacturing** (по умолчанию)
   - Продажа услуг швейной фабрики
   - Квалификация заказов на пошив одежды
   - Бизнес-логика швейного производства

2. **ai_seller_self** (новый!)
   - Продажа AI-ботов для бизнеса
   - Квалификация потенциальных клиентов
   - Демонстрация возможностей AI
   - 7-этапная воронка продаж

## 📋 Воронка Продаж (7 этапов)

### 1. GREETING - Приветствие
- Установление контакта
- Представление (Алекс, помощник по автоматизации)
- Вызов интереса

### 2. QUALIFY - Квалификация
**Собираемые данные:**
- Ниша бизнеса
- Объем заявок в месяц
- Каналы поступления заявок

**Дисквалификация если:**
- Меньше 10 заявок/месяц
- Неподходящая ниша (гемблинг, криптa)

### 3. DIAGNOSE - Диагностика
**Выявляем:**
- Главную боль клиента
- Текущее решение
- Уровень принятия решений (ЛПР?)

**Типичные боли:**
- Медленный ответ клиентам
- Нет обработки ночью/выходные
- Перегрузка менеджеров
- Низкая конверсия

### 4. DEMO - Демонстрация
**Показываем:**
- Как AI-бот решает их боль
- Примеры диалогов
- Кейсы из аналогичной ниши
- ROI калькуляцию

### 5. OFFER - Предложение
**Пакеты:**
- **Базовый** (50 000₽) - до 50 заявок/месяц
- **Стандарт** (150 000₽) - 50-200 заявок/месяц
- **Премиум** (300 000₽) - 200+ заявок/месяц

**Обоснование через ROI**

### 6. OBJECTIONS - Работа с возражениями
**Обрабатываем:**
- "Дорого"
- "Нужно подумать"
- "У нас уже есть чат-бот"
- "Не уверен что сработает"
- "Долго внедрять"
- "Нет бюджета"

### 7. CLOSE - Закрытие
**Собираем:**
- Имя
- Телефон
- Email (опционально)
- Название компании

**Next steps:**
- Созвон с техническим специалистом
- Подготовка КП
- Демо на реальных данных

## 🧠 Система Обучения

### Как работает?

**Epsilon-Greedy алгоритм:**
- 80% времени - выбирает лучший вариант (exploitation)
- 20% времени - тестирует альтернативы (exploration)

**Что учитывается:**
- Success rate (% успешных диалогов)
- Confidence (количество попыток)

### Пример:

Есть 3 варианта приветствия:
```
greet_v1: trials=50, successes=35 → success_rate=70%
greet_v2: trials=30, successes=15 → success_rate=50%
greet_v3: trials=10, successes=3  → success_rate=30%
```

Бот будет:
- В 80% случаев выбирать `greet_v1` (лучший)
- В 20% случаев тестировать `v2` и `v3`

Со временем данных станет больше и выбор улучшится!

### Добавление новых вариантов

В коде (`flow_manager.py` или где используется):
```python
from utils.simple_learner import get_learner

learner = get_learner()

# Добавить варианты
learner.add_variants("greeting:ai_seller_self", [
    ("greet_v1", "Привет! Я Алекс..."),
    ("greet_v2", "Здравствуйте! Меня зовут Алекс..."),
    ("greet_v3", "Добрый день! ...")
])

# Выбрать вариант
variant_id, content = learner.select_variant("greeting:ai_seller_self")

# После диалога - зафиксировать результат
learner.record_outcome("greeting:ai_seller_self", variant_id, success=True)
```

## 📊 Логирование Диалогов

### Что собирается?

**Основные данные:**
- Все сообщения (user + assistant)
- Timestamps
- Переходы по состояниям
- Собранные slots

**Lead attributes (для анализа):**
- Ниша бизнеса
- Объем заявок
- Боли и потребности
- Уровень принятия решений
- Бюджет
- Сегмент клиента
- Поведенческие метрики

**События:**
- Возражения
- Долгие паузы
- Падение sentiment
- И др.

### База данных

**Таблицы:**
- `conversations` - основные данные диалогов
- `messages` - все сообщения
- `state_transitions` - переходы по этапам
- `conversation_events` - события
- `outcome_feedback` - результаты от админа (/result)

**Файл:** `conversations.db` (SQLite)

### Использование для обучения

Система анализирует:
- Успешные диалоги → что работает?
- Проваленные диалоги → где проблема?
- Паттерны поведения клиентов
- Эффективность разных подходов

## 🚨 Troubleshooting

### Бот работает в старом режиме

**Проблема:** Бот все еще про швейку, а не про AI-ботов

**Решение:**
```bash
# Проверить .env
cat .env | grep AI_SELLER_DOMAIN

# Должно быть:
AI_SELLER_DOMAIN=ai_seller_self

# Перезапустить бота
pkill -f polling_bot
python3 polling_bot.py
```

### Админ-команды не работают

**Проблема:** Бот отвечает "⛔ Эта команда доступна только администраторам"

**Решение:**
```bash
# Проверить ADMIN_CHAT_IDS в .env
cat .env | grep ADMIN_CHAT_IDS

# Узнать свой chat_id
# Написать @userinfobot в Telegram

```
